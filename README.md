# MediBook – Doctor Appointment System
A PHP and MySQL based web application for managing doctor appointments.

### Features

* Patient registration and login
* Doctor search and profiles
* Appointment booking and cancellation
* Doctor appointment management
* Admin dashboard
* Role-based authentication

### Tech Stack

PHP, MySQL, HTML, CSS, JavaScript, XAMPP, phpMyAdmin

### How to Run

1. Start **Apache** and **MySQL** in XAMPP.
2. Place the project inside `C:\xampp\htdocs\`.
3. Open `http://localhost/phpmyadmin/`.
4. Import the SQL file from the `database/` folder.
5. Open the project:

```text
http://localhost/MediBook/
```
